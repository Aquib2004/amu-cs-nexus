# AMUCS Nexus - Documentation

Engineering documentation for AMUCS Nexus. Each directory explains both WHAT the subsystem does and WHY it is built that way.

- `architecture` - system architecture and data flows.
- `api` - REST API design and HTTP semantics.
- `database` - database design and storage boundaries.
- `ingestion` - crawling, parsing, cleaning, chunking, indexing.
- `rag` - retrieval and RAG pipeline design.
- `security` - security model and hardening.
- `deployment` - deployment and operational notes.
- `development` - project status and development guidance.
- `decisions` - architecture decision records (ADR).

Not all documents exist yet.
